# camt053-loader-mt942 v0.0.24

## Highlights ⭐️

* **Python 3.11 or newer**: Python 3.10 is no longer supported, in step with the rest of the camt053 suite. 3.10 reaches end of life this month, and pip on 3.10 keeps installing 0.0.23.
* **In lockstep with camt053 0.0.24**: this package requires `camt053` 0.0.24 or newer, below 1, so every member of the suite ships and resolves the same version.
* **Audit tooling off advised filelock**: the hash-pinned `pip-audit` tree used by CI now floors `filelock` at 4.2.1, past three advisories. `parse_mt942` returns the same document for the same input as 0.0.23.
